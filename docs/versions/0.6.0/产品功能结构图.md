# 产品功能结构图

```
My Notes（V0.6）
├── 1. 账号（本地）
│   └── 本地账户（无登录；用户信息页导出 / 导入旧项目·站点 JSON）
│
├── 2. Web 端（apps/web）— 桌面端复用同一套 UI
│   ├── 2.0 文件管理（FileManagerPage）★ 主线
│   │   ├── 多级目录树（新建 / 重命名 / 删除）
│   │   ├── 文件：新建 .md / .rm、重命名、删除
│   │   ├── .md：Markdown 源码编辑 + 普通预览
│   │   ├── .rm：定制阅读（凭证表 / 代码仓库表 / 通用表 + 复制；无站点镜像）
│   │   └── 数据：fs_folders / fs_files（Dexie version 2）
│   │
│   ├── 2.0b 差异测试（DiffLabPage）
│   │   ├── 左/右：选 fs 文件或粘贴
│   │   ├── Unified / 并排审阅
│   │   ├── 按 hunk 裁决（保留左 / 右 / 编辑）→ 合并预览
│   │   └── 纯函数：@my-notes/shared text-diff（后续导入 / 同步复用）
│   │
│   ├── 2.1～2.5 冻结模块（可展示，不再迭代；计划废弃）
│   │   ├── 笔记区（NotesPage）
│   │   ├── 站点信息区（SitesPage）
│   │   ├── 项目文档（ProjectMarkdownPage）
│   │   ├── 项目信息区（ProjectsPage）
│   │   └── 云盘工作台（CloudDrivePage）
│   │
│   └── 2.6 全局
│       ├── 路由导航（文件管理优先；旧入口保留）
│       ├── 全局搜索（笔记 / 站点条目 / 项目条目；尚未含 fs_*）
│       ├── Ant Design 中文主题
│       └── 本地存储（IndexedDB / Dexie，库名 my_notes_v2）
│
├── 3. 桌面端（apps/desktop）
│   ├── Electron 壳 + 加载 web 静态资源
│   ├── 托盘 / 全局快捷键 / 单实例
│   └── Windows .exe（NSIS + Portable）
│
└── 4. 共享包（packages/）
    ├── @my-notes/shared — 类型、createId、text-diff（类 git hunk）
    └── @my-notes/local-db — NotesDB（version 1 旧表 + version 2 增加 fs_*）
```

## 主线数据流

```
用户操作 → FileManagerPage Hooks → Dexie fs_folders / fs_files → useLiveQuery 刷新 UI
.rm 阅读 → 分段解析特殊表头 → 表格渲染 + 一键复制（不写 site_items）
差异测试 → computeTextDiff → hunk 裁决 → applyHunkResolutions → 合并预览（不落库）
```
