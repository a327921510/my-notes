# 产品功能结构图

**基线版本**：`1.0.0`（重构后全新拓扑；`1.0.0` 之前的功能树整体作废）

---

## 1. 功能拓扑

```
My Drive（1.0.0）
│
├── 1. 账号体系（数据隔离边界）
│   ├── 注册（邮箱 + 密码 ≥8 位 + 确认密码 → 自动登录 + 创建根目录）
│   ├── 登录（邮箱 + 密码 → JWT）
│   ├── 会话（路由守卫 / 401 过期跳登录 / 退出清空本地）
│   ├── 账号信息（邮箱、注册时间、用量与配额、文件与目录计数）
│   ├── 修改密码（旧会话失效，需重新登录）
│   └── 隔离保证（userId 取自 JWT / 越权返回 404 / 下载须鉴权 / 切号不残留）
│
├── 2. 云盘（主功能，交互对齐电脑文件管理器）
│   ├── 2.1 浏览与导航
│   │   ├── 目录树（无限层级、懒加载）
│   │   ├── 内容列表（目录优先，列：名称 / 大小 / 类型 / 修改时间）
│   │   ├── 面包屑（逐级跳转，过长折叠）
│   │   ├── 排序（名称 / 大小 / 修改时间，升降序）
│   │   └── 页面态（加载骨架 / 空态引导 / 错误态重试）
│   │
│   ├── 2.2 文件夹操作
│   │   ├── 新增（当前目录，进入重命名态）
│   │   ├── 重命名（根目录禁止）
│   │   ├── 删除（递归 + 二次确认写明子项数量；根目录禁止）
│   │   ├── 移动（拖拽 / 「移动到…」；禁止移入自身子孙）
│   │   └── 批量操作 → 见 2.4
│   │
│   ├── 2.3 文件操作
│   │   ├── 新增（点击多选 / 拖拽上传，逐项进度与重试）
│   │   ├── 重命名（改到 / 改掉 .mmd 触发类型升降级确认）
│   │   ├── 删除（二次确认，释放存储对象）
│   │   ├── 下载（鉴权文件流）
│   │   ├── 批量操作 → 见 2.4
│   │   └── 预览 —— 不支持（无缩略图；.mmd 除外，见 3）
│   │
│   ├── 2.4 批量操作
│   │   ├── 选择（复选框 / Shift 连选 / Ctrl·Cmd 点选 / 全选当前目录）
│   │   ├── 批量删除（二次确认，区分目录与文件数量）
│   │   ├── 批量移动（目标选择 + 同名策略）
│   │   ├── 批量下载（打包 ZIP，保留相对结构）
│   │   └── 结果汇总（成功数 / 失败数 / 失败原因，部分失败不回滚）
│   │
│   ├── 2.5 命名与冲突
│   │   ├── 命名约束（非空、1~255、禁非法字符、非 . 与 ..）
│   │   ├── 同级唯一（去空格 + 忽略大小写；服务端唯一索引兜底）
│   │   └── 同名策略 onConflict（保留副本 / 覆盖 / 跳过，可对本批全部应用）
│   │
│   ├── 2.6 搜索（当前账号，仅按目录名 + 文件名；结果显示所在路径，可直接操作）
│   │
│   └── 2.7 存储用量（已用 / 配额进度条；超配额禁用上传与导入）
│
├── 3. .mmd 文档（系统专属格式，云盘内的一等文件类型）
│   ├── 格式（扩展名 .mmd；UTF-8 纯文本；CommonMark + GFM 超集）
│   ├── 在云盘中（新建 / 打开 / 重命名升降级 / 删除 / 移动 / 批量 / 导出，规则同普通文件）
│   ├── 编辑（Markdown 源码编辑；手动保存 + Ctrl·Cmd+S；脏标记与离开拦截）
│   ├── 预览（渲染 Markdown；唯一支持系统内查看的文件类型）
│   ├── 专属语义块：凭据表
│   │   ├── 触发（表头依次为 地址 | 账号 | 密码 | 备注 的 GFM 管道表）
│   │   ├── 账号 / 密码列以纯文本展示（不渲染链接等语法）
│   │   ├── 地址列可作链接打开
│   │   └── 单元格悬停高亮、点击复制 + 轻提示
│   └── 并发编辑差异对比（多设备各自编辑时的唯一差异对比场景）
│       ├── 触发（保存时基版本已过期自动进入；工具栏「与服务端对比」主动进入）
│       ├── 对比对象（本机版本 ←→ 服务端版本，逐行 LCS diff 聚合为变更块）
│       ├── 展示（统一视图 / 分栏视图切换；双侧行号栏；GitHub 风格增删配色；增删行数统计）
│       ├── 决策（用本机版本覆盖 / 采用服务端版本（二次确认）/ 手动合并）
│       └── 边界（两侧一致则提示无差异直接保存；超 6000 行跳过逐行对比；无自动合并、无历史版本）
│
├── 4. 离线导入 / 导出（数据可带走）
│   ├── 导出
│   │   ├── 单文件下载 / 多选打包 / 单目录子树 / 全盘导出
│   │   ├── ZIP 为真实目录嵌套真实文件（.mmd 为原文）
│   │   └── 根部 .mydrive-manifest.json（版本、时间、账号、路径 / 大小 / MIME / SHA-256 / 时间戳）
│   └── 导入
│       ├── 选 ZIP（桌面端可直接选本地目录）→ 选目标目录
│       ├── 预检（目录数 / 文件数 / 总大小 / 冲突数 / 配额校验）
│       ├── 还原（逐级 create-or-reuse；清单校验保真；兼容外部普通 ZIP）
│       └── 结果明细（成功 / 跳过 / 失败可重试；单项失败不中断）
│
└── 5. 全局
    ├── 布局（Header：产品名 / 搜索 / 用量摘要 / 用户菜单 + 主内容区）
    ├── 路由（/login、/drive、/drive/doc/:nodeId、/account）
    ├── 交互规范（危险操作二次确认 / 进度反馈 / 页面态齐备 / 按钮防重）
    └── 文案（中文；界面不出现「同步 / 未同步 / 推送 / 拉取 / 冲突」等概念）
```

## 2. 端与模块关系

```
┌──────────────────────────┐        ┌──────────────────────────┐
│   apps/desktop（主交付）   │        │   apps/web（本地验证）    │
│  Electron 壳              │        │  浏览器运行               │
│  · 加载同一 React 应用     │        │  · 同一 React 应用        │
│  · 原生：选目录 / 选保存路径│        │  · 浏览器下载 / 文件选择  │
└─────────────┬────────────┘        └────────────┬─────────────┘
              │                                   │
              └──────────┬────────────────────────┘
                         │  HTTP + JWT（Axios，userId 只来自 token）
                         ▼
             ┌───────────────────────────┐
             │   apps/api（唯一事实来源） │
             │  auth / drive / docs      │
             │  export / import          │
             └──────┬─────────────┬──────┘
                    ▼             ▼
          SQLite（Drizzle）   磁盘对象存储
          users               uploads/<userId>/<storageId>
          drive_nodes
          storage_objects
                    ▲
                    │  类型 + 纯函数（命名校验 / 同名去重 / .mmd 分段）
             ┌──────┴───────┐
             │packages/shared│
             └──────────────┘
```

**要点**

- **服务端权威**：客户端无业务数据副本，不存在同步状态、双向合并、冲突副本与删除墓碑。唯一的版本比较是 `.mmd` 保存时在内存中做的逐行 diff（见 1-3）。
- **目录与文件统一节点表**（`drive_nodes` + `kind`），文件管理器语义（重命名 / 移动 / 批量 / 同级唯一名 / 路径）在一张表上表达。
- **两端功能等价**：桌面端与 Web 端共用同一 React 应用，差异仅在文件对话框与窗口菜单。

## 3. 页面与功能对应

| 路由 | 页面 | 承载功能 |
| --- | --- | --- |
| `/login` | 登录 / 注册页 | 1 账号体系（注册、登录） |
| `/drive` | 云盘工作台 | 2 云盘全部；4 导入导出入口；3 中的新建 `.mmd` |
| `/drive/doc/:nodeId` | `.mmd` 文档页 | 3 编辑 / 预览 / 凭据表 |
| `/account` | 账号信息页 | 1 账号信息、修改密码、用量 |

## 4. 已作废的功能域

以下功能在 `1.0.0` 中**不存在**，功能树里不再保留任何位置：笔记区（文件夹 + 富文本 + 图片）、站点信息区（站点空间 / 短文本 / 域名隔离）、项目信息、项目文件与项目文档页、旧云盘（目录表 + 文件表 + 墓碑 + **目录 / 文件级**同步对比）、浏览器扩展端、本地优先与手动推送 / 拉取。

沿用的历史设计只有两项，都收在 `.mmd` 文档域内（见 1-3）：

| 沿用 | 变化 |
| --- | --- |
| Markdown **凭据表增强** | 重建为 `.mmd` 的专属语义块 |
| **逐行文本差异对比**（LCS diff、统一 / 分栏视图、GitHub 风格行号与配色） | 对比逻辑与展示方式原样沿用；作用域从"云盘目录 / 文件同步预览"收敛为"`.mmd` 多设备并发编辑差异"，文件清单与 A/M/D 标记因单文档场景不再需要 |
