# 产品需求文档（PRD）

**项目名称**：My Notes  
**版本**：V0.7（文件管理 + 路径导入冲突裁决）  
**文档状态**：评审稿  
**日期**：2026-07-15

---

## 1. 产品背景与定位

My Notes 收敛为**纯本地优先的文件管理工具**：多级目录 + `.md` / `.rm`，配合类 git 的文本差异与导入冲突人工裁决。跨设备迁移通过「文件管理 JSON 导出 / 导入」完成。桌面端复用 Web UI。

V0.7 **已移除 UI**：笔记区、站点信息区、项目文档、项目信息区、云盘（对应页面代码删除，IndexedDB 旧表保留但不暴露）。

---

## 2. 产品目标

- 文件管理主线：树形目录、`.md` / `.rm` 编辑与 `.rm` 定制阅读。
- 导出 / 导入仅覆盖 `fs_*`；导入按路径 diff，冲突界面人工裁决；仅本地文件可选保留 / 删除。
- 差异测试页继续用于联调 text-diff，正式导入走用户信息页。
- 隐私：数据仅本地 IndexedDB。

---

## 3. 产品范围

### 3.1 In Scope

- `/files` 文件管理、`/diff-lab` 差异测试、`/user` 用户信息（fs 备份）。
- `fsBackup` JSON `formatVersion: 2`。
- 全局搜索：`fs_files` 路径 / 名 / 正文。

### 3.2 Out of Scope

- 远端同步、登录、旧 notes/drive 迁入 `fs_*`。
- 删除 IndexedDB 物理旧表。
- 二进制文件、目录树 diff。

---

## 4. 关键概念

| 概念 | 说明 |
| --- | --- |
| 文件管理 | 多级目录 + `.md` / `.rm` |
| `.rm` | README 定制 Markdown；特殊表渲染 + 复制，无站点镜像 |
| 路径 | 导出/导入以 `/a/b/file.rm` 匹配 |
| 导入冲突 | 同路径内容不同 → hunk 裁决（左本地 / 右导入） |
| 仅本地 | 导入包无此路径 → 用户选保留或删除（默认保留） |

---

## 5. 功能需求

### 5.1 文件管理（`/files`）

同 V0.6：目录 / 文件 CRUD、`.md` / `.rm` 编辑；支持搜索跳转 `focusFileId`。

### 5.2 差异测试（`/diff-lab`）

粘贴或选文件比对与裁决，**不落库**。

### 5.3 用户信息与 fs 备份（`/user`）

- **导出**：`folders[]` + `files[]`，`formatVersion: 2`。
- **导入**：解析后跳转「导入确认」页（`/user/import-confirm`）→ 分类 → 冲突裁决 / 仅本地保留·删除 → 事务写入 → 跳转文件管理。
- 拒绝 `formatVersion: 1` 旧站点备份并提示。

### 5.4 全局搜索

命中 `fs_files`，跳转 `/files` 并选中文件。

### 5.5 桌面端

沿用既有 Electron 能力。
