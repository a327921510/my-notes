## 2. 产品定位与目标

### 2.1 产品定位

一款**个人云盘**：以账号为边界存放和管理自己的文件与目录，操作体感与常见的电脑文件管理器 / 网盘客户端一致；并内置一种系统专属的文档格式 `.mmd`，可以直接在云盘里新建、编辑与预览。

### 2.2 核心目标

1. **账号即边界**：注册 / 登录后进入自己的空间，任何数据读写都被账号强隔离，不同账号之间互不可见、互不可达。
2. **云盘像文件管理器**：目录树 + 文件列表 + 面包屑，目录与文件的增删改查、重命名、移动、批量操作齐备，无需理解任何"同步"概念。
3. **文档能力内建**：`.mmd` 是云盘里的一等公民文件类型，支持新建 / 编辑 / 预览三态闭环。
4. **数据可带走**：支持离线导入导出，导出产物是普通目录结构的 ZIP，脱离本系统也能直接打开。

### 2.3 成功标准

- 用户可完成闭环：注册 → 登录 → 建目录 → 上传文件 → 重命名 / 移动 / 批量删除 → 下载。
- 用户可完成闭环：在云盘中新建 `.mmd` → 编辑并保存 → 预览渲染正确。
- 用户可完成闭环：导出目录为 ZIP → 在另一账号或另一设备导入 → 目录结构与文件内容一致。
- 两个不同账号登录后，任何入口都无法看到或访问对方的目录与文件。

## 3. 产品范围

### 3.1 本期范围（In Scope）

- 账号体系：注册、登录、退出、当前用户信息、修改密码、按账号隔离数据。
- 云盘：多级目录树；目录增 / 删 / 查 / 重命名 / 移动 / 批量操作；文件上传 / 下载 / 删除 / 查 / 重命名 / 移动 / 批量操作。
- `.mmd` 文档：在云盘内新建、编辑、预览。
- 离线导入导出：单文件下载、多选与目录打包 ZIP 导出、ZIP 导入还原。
- 存储用量与配额展示。

### 3.2 非本期范围（Out of Scope）

- 文件预览（图片 / PDF / 视频 / Office 等一律不预览，`.mmd` 是唯一例外，见 §7.3）。

- 文件版本历史、回收站还原（回收站见 §16-Q5）。
- 浏览器扩展端、移动端 App、小程序。
- 服务器部署与运维（Web 端仅本地启动用于验证，见 §4）。
- 端到端加密、文件内容加密存储。
- 全文内容检索（仅按文件名 / 目录名检索，见 §7.2.7）。

## 5. 关键概念与术语

### 5.1 同步模型：服务端权威（Server-Authoritative）

本产品**不做本地优先，也不做手动同步**。

- 目录树、文件二进制、`.mmd` 正文的唯一事实来源是**后端**。
- 客户端（Web / 桌面端）的任何操作都是对后端的**在线读写**，成功即生效，失败即回滚并提示，不存在"待同步""已修改未上传"等中间状态。
- 客户端本地只保留**请求缓存与上传队列**等易失状态，不维护业务副本，因此不存在双向合并、冲突判定、删除墓碑。

> 该模型是本次重构最重要的取舍：需求要求"和平常云盘软件电脑文件管理功能一致"，常规云盘就是在线即时生效；引入本地副本会把简单 CRUD 重新变成同步引擎。相关确认见 §16-Q1、§16-Q2。

### 5.2 术语表

| 术语 | 定义 |
| --- | --- |
| **账号（Account）** | 以邮箱唯一标识的用户实体，是数据隔离的唯一边界。 |
| **云盘空间（Drive Space）** | 一个账号名下的全部目录与文件，有唯一根目录。 |
| **节点（Node）** | 云盘中的一个条目，`kind` 为 `folder` 或 `file`；目录树与文件列表都由节点组成。 |
| **根目录（Root）** | 每个账号自动拥有、不可重命名、不可删除、不可移动的顶层目录。 |
| **路径（Path）** | 由根目录到某节点的名称序列，如 `/工作/项目A/说明.mmd`；用于面包屑与导出目录结构。 |
| **`.mmd` 文档** | 系统专属文档格式，Markdown 超集，纯文本存储；云盘中的一种文件类型。 |
| **同名策略（onConflict）** | 上传 / 移动 / 导入时目标目录已存在同名节点的处理方式：`rename`（保留副本）/ `overwrite`（覆盖）/ `skip`（跳过）。 |
| **导出包（Export Archive）** | 以真实目录嵌套真实文件构成的 ZIP，根部含清单文件，可被任意解压工具打开。 |

## 6. 角色与权限

本期只有一种角色：**已登录的普通用户**。

| 主体 | 可访问范围 |
| --- | --- |
| 未登录访客 | 仅登录 / 注册页；**不可**使用云盘任何功能（见 §16-Q4） |
| 已登录用户 | 仅自己账号名下的节点与 `.mmd` 正文，读写皆可 |
| 其他账号的数据 | 任何入口均不可见、不可读、不可写 |

**隔离实现要求（硬性）**：

1. 服务端所有云盘接口从 JWT 中解析 `userId`，并把 `userId` 作为查询与写入的**强制条件**，不接受客户端传入的 `userId`。
2. 访问不属于当前账号的节点 ID 时，返回 `404`（不区分"不存在"与"无权限"，避免探测他人节点是否存在）。
3. 文件二进制的下载地址必须经过鉴权，不提供任何公开可访问的直链。
4. 客户端在退出登录时清空全部本地缓存与内存态；切换账号不得残留上一个账号的目录树、列表、编辑器草稿。

## 7. 功能需求

### 7.1 账号体系

#### 7.1.1 注册

- 入口：登录页的「注册」切换。
- 字段：邮箱（必填、格式校验）、密码（必填、≥ 8 位）、确认密码（必填、需与密码一致）。
- 邮箱按小写去空格归一化后**全局唯一**；已存在时提示"该邮箱已注册"并提供切回登录。
- 注册成功即视为登录成功：签发会话并进入云盘根目录。
- 注册成功时后端为该账号创建根目录（幂等）。

#### 7.1.2 登录

- 字段：邮箱、密码。
- 成功：签发 JWT，客户端持久化 token 与用户摘要（邮箱、注册时间），跳转到进入前的目标路由或云盘根目录。
- 失败：统一提示"邮箱或密码不正确"，不区分邮箱是否存在。
- 不提供任何免密 / 演示账号的旁路登录（历史实现中的开发环境 `demo` 免密登录一并删除）。

#### 7.1.3 会话与登出

- 前端路由守卫：无有效会话访问受保护路由时，重定向到登录页并记录来源路由。
- token 过期或被拒（接口返回 `401`）时：清理会话、提示"登录已过期，请重新登录"、跳登录页；不得静默失败。
- 登出：清理 token、用户摘要与所有本地缓存（含目录树缓存、列表缓存、编辑器草稿）。

#### 7.1.4 账号信息与修改密码

- 账号页展示：邮箱、注册时间、存储用量（已用 / 配额 / 百分比）、文件与目录计数。
- 修改密码：输入当前密码 + 新密码（≥ 8 位）+ 确认新密码；成功后使旧会话失效并要求重新登录。
- 注销账号（删除账号及其全部数据）：本期不做。

#### 7.1.5 数据隔离的用户可见行为

- 账号 A 与账号 B 在同一台设备先后登录，各自只能看到自己的云盘内容。
- 账号 A 导出的 ZIP 由账号 B 导入后，内容归属 B，A 不受影响。

### 7.2 云盘（文件管理）

云盘是产品主界面，交互基线是**常见电脑文件管理器**：左侧目录树、右侧当前目录内容列表、顶部面包屑与操作栏。

#### 7.2.1 浏览与导航

- **目录树**：从根目录展开，支持无限层级；点击目录节点切换当前目录；懒加载子层级。
- **内容列表**：展示当前目录下的直接子节点，目录优先于文件排序。
- 列表列：名称（带类型图标）、大小（目录显示 `-`）、类型、修改时间。
- **面包屑**：显示当前目录完整路径，每一级可点击跳转；层级过多时中间折叠。
- **排序**：按名称 / 大小 / 修改时间升降序切换；默认名称升序、目录在前。
- **空状态**：空目录展示引导文案 + 「新建文件夹」「上传文件」「新建 .mmd」主按钮。
- **加载与错误态**：列表加载中显示骨架；请求失败展示错误态与「重试」。

#### 7.2.2 文件夹操作

| 操作 | 规则 |
| --- | --- |
| **新增** | 在当前目录创建；名称必填、去首尾空格后非空；默认名「新建文件夹」并进入重命名态 |
| **重命名** | 就地编辑或弹窗；受 §7.2.6 命名约束；根目录不可重命名 |
| **删除** | 递归删除该目录及其全部子目录与文件；删除前二次确认，确认文案须给出将被删除的子项数量；根目录不可删除 |
| **查询** | 见 §7.2.1 浏览、§7.2.7 搜索 |
| **移动** | 拖拽到目录树 / 列表中的目录，或通过「移动到…」目录选择器；不允许移动到自身或自身子孙目录（须拦截并提示） |
| **批量操作** | 见 §7.2.5 |

#### 7.2.3 文件操作

| 操作 | 规则 |
| --- | --- |
| **新增（上传）** | 支持点击选择（多选）与拖拽到列表区；上传到当前目录；显示逐个文件的进度、成功、失败与「重试」 |
| **重命名** | 就地编辑或弹窗；受 §7.2.6 命名约束；扩展名可修改，修改为 / 修改掉 `.mmd` 时按 §7.3.2 处理 |
| **删除** | 二次确认后删除；同时释放其存储对象 |
| **下载** | 单文件下载，走鉴权接口返回文件流；文件名为节点当前名称 |
| **查询** | 见 §7.2.1、§7.2.7 |
| **移动** | 同 §7.2.2 |
| **批量操作** | 见 §7.2.5 |
| **预览** | **不支持**。双击非 `.mmd` 文件等同于下载；不生成缩略图、不内嵌任何查看器（含图片，见 §16-Q6） |

#### 7.2.4 上传细则

- 支持一次选择多个文件；不支持整目录上传（目录级导入走 §7.4 导入）。
- 单文件大小上限与账号总配额可配置，默认值见 §16-Q9；超限在**上传前**拦截并明确提示。
- 允许 0 字节文件。
- 同名处理：目标目录已存在同名文件时，弹出选择「保留副本」/「覆盖」/「跳过」，并提供「对本批全部应用」。
  - 保留副本：追加序号，如 `报告.pdf` → `报告(1).pdf`。
  - 覆盖：替换内容与大小、更新修改时间，节点 ID 不变。
- 上传过程中可取消单个任务；已完成的任务不回滚。
- 上传失败（网络 / 超限 / 服务异常）不影响同批其他文件；失败项可单独重试。

#### 7.2.5 批量操作

- 选择方式：行首复选框、`Shift` 连选、`Ctrl/Cmd` 点选、「全选当前目录」。
- 选中后展示批量操作条：已选数量、批量删除、批量移动、批量下载、取消选择。
- **批量删除**：二次确认；确认文案区分目录与文件数量，并声明目录为递归删除。
- **批量移动**：选择目标目录；同名冲突按 §7.2.4 同名策略处理；不允许把目录移动进自身子孙。
- **批量下载**：多选（含目录）打包为 ZIP 下载，ZIP 内保留相对目录结构，规则与 §7.4 导出一致。
- 批量操作以整体任务反馈结果：成功数、失败数、失败原因清单；部分失败不回滚已成功项。

#### 7.2.6 命名约束（目录与文件统一）

1. 去首尾空格后不可为空；长度 1～255 字符。
2. 不允许包含 `/ \ : * ? " < > |` 与控制字符。
3. 不允许为 `.` 或 `..`。
4. **同一父目录下名称唯一**，比较时去首尾空格并忽略大小写（`Report.txt` 与 `report.txt` 视为同名）。
5. 违反 1～3 前端即时校验并阻止提交；违反 4 时按同名策略处理或提示"该名称已存在"。

#### 7.2.7 搜索

- 搜索范围：**当前账号名下的节点名称**（目录名 + 文件名），不检索文件内容。
- 交互：顶部搜索框输入关键词，展示扁平结果列表，每行显示所在路径；点击结果定位到其所在目录并高亮。
- 支持在结果上直接执行重命名 / 删除 / 下载 / 移动。
- 关键词为空时退回普通目录浏览视图。

#### 7.2.8 存储用量

- 云盘页展示当前账号已用容量与配额（进度条）。
- 用量超过配额时，上传与导入入口置为不可用并提示"存储空间不足"。

### 7.3 `.mmd` 文档

#### 7.3.1 格式定义

- **扩展名**：`.mmd`（My Markdown Document）。
- **本质**：UTF-8 纯文本的 **Markdown 超集**——遵循 CommonMark + GFM 表格，在此之上定义系统专属的语义块（§7.3.4）。
- **存储**：作为云盘中的普通文件节点存储（`kind = file`，标记 `docKind = mmd`），参与目录树、重命名、移动、删除、批量操作、导入导出的全部规则。
- **选型理由**：纯文本使得导出产物脱离本系统也能被任意 Markdown 工具打开，与 §2.2「数据可带走」一致；专属扩展名使系统能够识别并提供编辑 / 预览能力。

#### 7.3.2 在云盘中的行为

| 场景 | 行为 |
| --- | --- |
| 新建 | 当前目录「新建 .mmd」；输入名称（自动补 `.mmd` 后缀）；创建后直接进入编辑态，初始内容为空 |
| 打开 | 单击选中、双击进入文档页（编辑 / 预览）；**这是唯一支持在系统内打开查看的文件类型** |
| 重命名 | 若把 `.mmd` 改为其他扩展名，节点降级为普通文件，不再可打开（须二次确认）；把普通文本文件改名为 `.mmd` 则升级为文档，可打开 |
| 删除 / 移动 / 批量 | 与普通文件完全一致 |
| 下载 / 导出 | 原文导出，内容为 `.mmd` 纯文本 |

#### 7.3.3 编辑与预览

- 文档页提供「编辑 / 预览」双态切换（默认进入**预览**，新建时进入**编辑**）。
- **编辑态**：Markdown 源码编辑器；纯文本编辑，不做富文本所见即所得。
- **预览态**：渲染 Markdown，并按 §7.3.4 渲染专属语义块。
- **保存**：手动保存（工具栏按钮 + `Ctrl/Cmd + S`）；有未保存改动时标题显示改动标记，离开页面或关闭窗口前二次确认。
- 保存成功后更新该节点的修改时间与大小；保存失败保留编辑内容并提示可重试。
- 并发编辑：同一文档在两处同时编辑时，以最后一次保存为准（后保存覆盖），保存前若检测到服务端修改时间已变化，提示"该文档已在别处被修改，是否覆盖"。

#### 7.3.4 专属语义块：凭据表

`.mmd` 相对标准 Markdown 的唯一增强能力，用于集中管理一组访问信息。

- **触发条件**：一个 GFM 管道表，且表头从左到右**依次**为 `地址`、`账号`、`密码`、`备注`。不满足则按普通 Markdown 表格渲染。
- **预览态渲染规则**：
  1. 渲染为增强表格，视觉上与普通表格区分。
  2. `账号`、`密码` 列**以纯文本展示**——即使单元格内容是链接或其他 Markdown 语法，也只显示其文字，避免误点与误渲染。
  3. `地址` 列可作为链接渲染并支持在系统默认浏览器打开。
  4. 单元格悬停高亮，**点击即复制**该单元格纯文本，并给出复制成功轻提示。
- **编辑态**：仍以 Markdown 源码形式编辑（管道表语法），编辑器提供插入凭据表模板的快捷操作。
- 除凭据表外，本期不引入其他专属语法（见 §16-Q3）。

### 7.4 离线导入 / 导出

目标：用户可以随时把云盘内容完整取走，也可以把外部目录结构搬进云盘；导出产物不依赖本系统即可读取。

#### 7.4.1 导出

| 入口 | 产物 |
| --- | --- |
| 单个文件「下载」 | 原始文件本身 |
| 多选「批量下载」 | ZIP，内含所选节点，保留相对目录结构 |
| 目录「导出为 ZIP」 | ZIP，内含该目录的完整子树 |
| 云盘根目录「全部导出」 | ZIP，内含整个账号云盘 |

- **ZIP 结构**：云盘目录对应 ZIP 内真实目录，云盘文件以**原始二进制**写入其相对路径；`.mmd` 以原文写入。
- **清单文件**：ZIP 根部写入 `.mydrive-manifest.json`，记录导出版本、导出时间、账号邮箱，以及每个条目的相对路径、类型、大小、MIME、校验值（SHA-256）、创建 / 修改时间，用于回导保真与完整性校验。
- 导出过程展示进度；大体量导出不阻塞界面操作。
- 桌面端可直接选择本地保存目录（原生保存对话框）；Web 端走浏览器下载。

#### 7.4.2 导入

- **入口**：云盘工具栏「导入」，选择 ZIP 文件；桌面端额外支持**直接选择本地目录**导入。
- **目标**：导入到当前目录（可在导入弹窗中改选目标目录）。
- **还原规则**：
  1. 按 ZIP 内目录结构逐级 create-or-reuse 目录，文件按相对路径写入。
  2. 若存在 `.mydrive-manifest.json`，用其校验条目完整性并还原 MIME 与时间戳；校验不通过的条目单独列出，由用户选择跳过或强制导入。
  3. **兼容外部普通 ZIP**（无清单文件）：仅按目录结构还原，MIME 按扩展名推断，时间戳取导入时间。
  4. ZIP 根部散落的文件按原名导入到目标目录。
  5. 同名冲突按 §7.2.4 同名策略处理，支持「对本次全部应用」。
- **反馈**：导入前展示预检结果（目录数、文件数、总大小、冲突数、超配额提示）；用户确认后执行；执行后展示成功 / 跳过 / 失败明细。
- 单个条目失败不中断整体导入；失败清单可导出或重试。
- 超出配额时在预检阶段拦截，不做部分写入。

## 9. 数据需求（逻辑模型）

### 9.1 设计要点

- **目录与文件统一为一张节点表**（`drive_nodes`），以 `kind` 区分。文件管理器的重命名、移动、批量、同级唯一名、路径计算等语义在统一表上表达最自然，也避免历史实现中目录表与文件表两套同步逻辑。
- **`userId` 是每张业务表的必备列**，并参与唯一索引，作为隔离的物理保证。
- **文件二进制不入库**：落盘为存储对象，节点表只保存 `storageId` 与元数据。

### 9.2 服务端实体

| 实体 | 关键字段 | 说明 |
| --- | --- | --- |
| `users` | `id`、`email`、`emailNormalized`(唯一)、`passwordHash`、`createdAt`、`updatedAt` | 账号 |
| `drive_nodes` | `id`、`userId`、`parentId`(根为空)、`kind`(`folder`/`file`)、`name`、`nameKey`(归一化名，唯一索引用)、`mimeType`、`sizeBytes`、`checksum`、`storageId`、`docKind`(`mmd`/空)、`createdAt`、`updatedAt` | 目录与文件节点；唯一索引 `(userId, parentId, nameKey)` |
| `storage_objects` | `storageId`、`userId`、`sizeBytes`、`checksum`、`createdAt` | 落盘文件对象与归属 |

- 每个账号有且仅有一个 `parentId` 为空、`kind = folder` 的根节点。
- `.mmd` 正文即其存储对象内容，不单独建表。
- 存储用量由 `SUM(drive_nodes.sizeBytes WHERE kind='file')` 聚合得到。

### 9.3 客户端数据

客户端**不建业务数据库**。

| 存放位置 | 内容 | 生命周期 |
| --- | --- | --- |
| 持久化存储（`localStorage` / 桌面端安全存储） | JWT、用户摘要（邮箱、注册时间） | 登出或过期即清除 |
| 内存 | 目录树与列表的请求缓存、选中态、上传队列、编辑器草稿 | 页面 / 窗口生命周期内；登出立即清空 |

历史实现中的 IndexedDB（Dexie）本地业务库**不再使用**，相关表与包一并移除（清理清单见开发文档）。

## 11. 交互与状态规范

- **危险操作二次确认**：删除目录（递归）、批量删除、覆盖同名文件、`.mmd` 改扩展名降级、修改密码。确认文案必须写明影响范围（数量 / 是否递归 / 是否不可恢复）。
- **进度反馈**：上传、批量下载、导出、导入均需显示进度与结果汇总（成功 / 跳过 / 失败数），失败项可查看原因并重试。
- **不可逆提示**：本期无回收站，删除即不可恢复，确认弹窗必须明示。
- **页面态齐备**：每个列表 / 文档区都需具备加载态、空态、错误态（含重试）、无权限态。
- **按钮防重**：进行中的操作按钮置为 loading 并禁用，避免重复提交。
- **反馈语言**：界面文案与错误提示统一中文；技术术语（`.mmd`、ZIP、JWT）保留英文。
- **不出现同步概念**：界面上不得出现"未同步""待上传""推送""拉取""冲突"等字样。

## 13. 验收标准与最小测试集

### 13.1 验收标准（DoD）

**账号**
- 注册 → 自动登录 → 进入云盘根目录；重复邮箱注册被拒。
- 错误密码登录被拒且提示不泄露邮箱是否存在。
- 修改密码后旧会话失效，需重新登录。
- 账号 A、B 交替登录，各自只见自己的数据；退出后本地无残留。

**云盘**
- 目录与文件的增 / 删 / 查 / 重命名 / 移动 / 批量操作全部可用且刷新后结果持久。
- 同一父目录创建同名（含仅大小写不同）被拒或按同名策略处理。
- 目录删除为递归删除且有二次确认，根目录不可删除 / 重命名 / 移动。
- 目录不能被移动到自身或其子孙目录。
- 多选批量删除 / 移动 / 下载均返回成功与失败明细。
- 非 `.mmd` 文件在系统内无任何预览入口。

**`.mmd`**
- 云盘内可新建 `.mmd`，编辑保存后刷新内容不丢。
- 预览态正确渲染 Markdown；表头为 `地址/账号/密码/备注` 的表渲染为凭据表，账号与密码列为纯文本，点击单元格复制成功。
- 未保存改动离开页面有拦截提示。

**导入导出**
- 目录导出 ZIP，解压后目录结构与文件内容与云盘一致，根部含清单文件。
- 该 ZIP 重新导入后云盘结构与内容一致；同名冲突按所选策略生效。
- 外部生成的普通目录 ZIP 可被导入。

## 14. 风险与应对

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 服务端权威模型下断网即不可用 | 桌面端体验受损 | 明确离线边界（§16-Q2）；断网时给出明确不可用提示而非静默失败；导入导出保证数据可带走 |
| 大文件 / 大目录上传导出耗时 | 界面卡顿、超时 | 流式读写、任务化进度、单文件上限；分片上传列为后置 |

| 统一节点表重构与历史数据不兼容 | 旧数据无法沿用 | 旧需求已整体作废，不做数据迁移；旧库与旧表直接废弃 |
| 桌面端为新增工程 | 打包与原生能力有未知成本 | 桌面端先以"加载同一 React 应用 + 原生文件对话框"的最小壳落地 |
