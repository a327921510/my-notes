# 需求 backlog

本目录是**需求留痕与工时**的入口，不是功能说明书。

| 文件 | 用途 |
|------|------|
| [REQ-index.md](./REQ-index.md) | 总台账（必用） |
| [\_template.md](./_template.md) | 单条需求详情模板（大需求/复杂 Bug 用） |
| `REQ-YYYYMMDD-XX-*.md` | 从模板复制出的具体需求 |

收到需求后的第一步：在 `REQ-index.md` 加一行。  
完整流程见项目已安装的 `req-workflow` skill（`WORKFLOW.md`）。
